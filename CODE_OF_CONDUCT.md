# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful and constructive, assume good intent, and keep
discussion about the work. Harassment, insults and personal attacks are not
accepted, in issues, pull requests or anywhere else the project is discussed.

## Reporting

To report behaviour that breaks this code, use GitHub's **Report content**
option on the comment, issue or pull request (the **…** menu). Reports are
handled privately.

## Enforcement

The maintainers may edit or remove comments, close issues and pull requests,
and block people from the repository, as the Contributor Covenant's
enforcement guidelines describe.
